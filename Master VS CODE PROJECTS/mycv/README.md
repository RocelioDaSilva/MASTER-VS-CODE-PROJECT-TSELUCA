# Minimal LaTeX CV

This is a minimal, single-file LaTeX CV template: [main.tex](main.tex)

## Compile

To compile with pdfLaTeX:

```bash
pdflatex main.tex
```

Or with XeLaTeX (if you want to use system fonts):

```bash
xelatex main.tex
```

Replace the placeholder content in `main.tex` with your own details.
