## 🔧 Comandos Disponíveis

### Bot
```powershell
cd bot
npm start          # Inicia o bot
npm run dev        # Dev mode com nodemon
npm install        # Instalar deps
```

### Painel
```powershell
cd painel
npm run dev        # Dev mode (http://localhost:3000)
npm run build      # Build de produção
npm run start      # Rodar build de produção
npm install        # Instalar deps
```

### Projeto
```powershell
# Windows
.\setup.bat        # Setup automático
.\start.bat        # Rodar bot + painel em paralelo
.\test-project.ps1 # Validar projeto

# Linux/Mac
bash setup.sh
bash start.sh
```
