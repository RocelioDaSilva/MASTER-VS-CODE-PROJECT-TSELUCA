## ☁️ Forma Ultra-Rápida (SEM APK)

```powershell
cd mobile-app
npx expo start --android
```

1. **PC:** Vais ver um QR code
2. **Samsung:** Baixa "Expo Go" (Play Store, grátis)
3. **Samsung:** Escaneia o QR code
4. **Pronto!** App abre ✅

Cada vez que quiser testar, apenas **execute o comando acima** novamente!

---

## 💾 Forma Permanente (COM APK)

Se quiser instalar como os outros apps (sem precisar escanear QR):

```powershell
npx eas build --platform android
# Espera 15 min
# Baixa APK
# Copia para Samsung via USB + toca para instalar
```

Mas para testar? **Expo Go é muito mais rápido!**
