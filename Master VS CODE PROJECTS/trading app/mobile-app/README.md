# 📱 Buscador Pessoal - React Native App

App para buscar suas ofertas no Samsung Galaxy A33.

---

## ⚡ COMECE AGORA - 5 MINUTOS, SEM LOGIN

### No PC:
```powershell
cd mobile-app
npx expo start --android
```

### No Samsung:
1. Baixe **"Expo Go"** na Play Store (grátis)
2. Abra o app
3. Escaneia o QR code que aparecerá no PC

**Pronto!** Seu app abre no celular 🎉
