# A Volta – The Sorcerers’ Return

A horror-fantasy universe where Angola’s independence was a sorcerous pact, and the death of the last *Nganga* unleashes ancestral power in every Angolan bloodline.

- **Logline:** When the spirits bound by the *Havemos de Voltar* vow are no longer controlled, every Angolan must awaken as a sorcerer—or be consumed by the land they forgot.
- **Central Question:** Can the *Mukixi* (the awakened) master the *Kimbanda* traditions before the *Makisi* and the *Bakululu* (betrayers) tear the nation apart?

## Project Structure

- /story – Narrative drafts, chapters, outline
- /worldbuilding – Magic system, spirits, factions, history
- /notes – Ideas, research, character sketches
- /resources – Maps, references, cultural inspirations

Start with story/outline.md or worldbuilding/sorcery.md.
