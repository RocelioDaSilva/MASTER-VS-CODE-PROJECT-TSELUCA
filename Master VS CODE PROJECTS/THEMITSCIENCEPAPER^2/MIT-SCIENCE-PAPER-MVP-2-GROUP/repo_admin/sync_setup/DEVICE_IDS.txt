### Quick Add Device (For each Laptop)
1. On laptop: Start Syncthing → http://127.0.0.1:8384
2. Note laptop Device ID from Devices → This Device → Identification
3. On NEXUS: Devices → Add Remote Device → Paste laptop ID
4. On laptop: Accept connection from NEXUS
5. Create/add folder share on both devices
6. Test sync with a small file

### Folder Share Configuration
- **Path:** Your workspace root directory
- **Label:** MIT-SCIENCE-PAPER or similar
- **Devices:** All computers in sync
- **Ignore Patterns:** Paste from .stignore.example

### Canonical Backup Command
After sync is complete, ensure all changes are backed to GitHub:
```bash
git add .
git commit -m "sync backup $(date)"
git push origin main
```
